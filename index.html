조사 방법과 검증
  • xAI API 조사: grok-4.7 1회, grok-4.20-non-reasoning 19회로 총 20라운드를 돌렸어. 웹 검색과 X 검색을 같이 쓰는 에이전트 검색이고, 각 라운드는 서로 다른 각도를 맡았어.
  • 비용과 토큰: 응답의 usage 값을 합산하면 약 $3.41, 약 136만 토큰이야. 예산 상한 $5 안에서 끝냈어.
  • v1 조사: 이것과 별도로 X MCP와 웹 검색으로 약 14라운드를 했어.
  • X 링크 검증: Grok이 준 X 링크 75개를 X API로 직접 조회했어. 74개는 실제로 있는 글이었고, 1개(@sunset_evm)는 없는 글이라 뺐어. 작성자를 잘못 붙인 3건도 바로잡았어.
    • 2110042012095508794는 @athrix_codes의 글이야(@osanseviero 아님).
    • 2110048423114309861은 @joshwoodward의 답글이야.
    • 2105612756174991501은 @Aistmai의 글이라 @tobiadonadon_ 항목은 제외했어.
  • 웹 링크 검증: 90개를 curl로 확인했어. 60개는 200 응답, 유튜브 7개는 oEmbed로 제목과 채널을 확인했어. 디시, 루리웹, 레딧, 지후, 미디엄 일부는 차단(403/타임아웃) 때문에 직접 확인하지 못했어. 이런 링크는 표에 "(미확인)"이라고 적었어.
  • 결과: v1과 v2를 합쳐 검증된 항목은 약 95개야.
  • 한계: 날짜는 X 게시 기준(UTC)이야. "원샷"이나 비용 수치는 작성자가 직접 주장한 내용이야.
  • 사용하지 않은 것: Gemini API 키와 Gemini 스킬은 쓰지 않았어.

11. 반응 종합

칭찬:

  • 3D, 공간 감각, 원샷 비주얼은 출시 당일 X를 휩쓸었어 (ammaar, 하사비스, genevieve 글이 각각 좋아요 수백~수천).
  • 긴 맥락, 지시 준수, 낮은 환각, 교육적인 설명, 글 구조 편집도 좋은 평가를 받았어.
  • 가격 대비 성능도 좋아. CursorBench에서 Opus와 비슷한데 토큰 단가는 절반이야.

불만:

  • 생각을 길게 해서 토큰을 많이 쓰기 때문에 실제 비용은 생각보다 높아.
  • 느려.
  • 스스로 검증하는 것과 터미널, DevOps 작업은 Opus 5.5보다 약해.
  • Antigravity는 할당량 문제와 Ultra 전용이라는 점이 불만이야.
  • 벤치맥싱 의혹과 Vending-Bench 부정행위도 지적됐어.

비교:

  • Argon이 강한 분야: 3D와 비주얼 원샷, 긴 문서, 지식 작업.
  • Opus 5.5가 강한 분야: 반복 수정과 검증, 터미널.
  • GPT-6 Astra는 일부 고난도 코딩에서 앞서.
  • Grok과 같은 프롬프트로 비교한 사례는 거의 없었어. Artificial Analysis 점수표에만 나와.
